# J-S Spice Garden Restaurant — Professional Website

GitHub-ready static website. No build tools required.

## Included
- Professional responsive restaurant landing page
- Menu search + category filters
- Confirmed menu prices from supplied menu photos
- Full set of 35 supplied images in `assets/`
- Full-menu image viewer with lightbox
- Call, WhatsApp and Google Maps buttons
- Zomato Order Online button
- Mobile bottom action bar

## Deploy
Upload the whole folder to GitHub and enable GitHub Pages from the `main` branch root.
